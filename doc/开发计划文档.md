# ScreenRecorderPlayer — 开发计划文档

## 1. 开发策略

五阶段渐进式开发，每个阶段交付可编译运行的版本。

### 原则

- 接口先行，实现后填
- 模块独立，逐阶段集成
- 前后端分离：前端 QWidget 负责 UI，后端 QObject 负责引擎和状态机
- C++17 + Modern CMake target 语法
- 每个阶段版本可通过 VS Code F5 一键调试

## 5. 第四阶段：视频播放功能

### 目标

VideoEngine 播放引擎完整实现（状态机 + 解码 + 线程），VideoPlayer 前后端贯通。

### 任务

- [ ] VideoEngine 状态机实现（Empty / Ready / Playing / Paused / Error）
  - openFile(): 校验 Empty 或 Ready → FFmpeg 解析 → 解码器初始化 → setState(Ready)
  - setPlaybackSpeed(int fps): 设置目标播放帧率（1–200），计算帧间间隔
  - play() / pause() / resume() / stop(): 各自校验 + 状态转移 + 线程控制
  - Playing/Paused/Error 期间 openFile() 被拒绝（comboBox disabled 作为第一道防线）
  - 播放到文件末尾自动 stop → Ready
  - Error 无自动恢复，必须 stop() → Ready
- [ ] AVFormat 文件解析 + 解码器初始化
- [ ] 解码线程：读取 → 解码 → SwsScale BGRA
- [ ] frameReady 信号将帧数据发送至主线程
- [ ] QOpenGLWidget 纹理上传与渲染
- [ ] 播放速度控制（fps 映射到帧间隔）
- [ ] VideoInfo 结构体输出 + videoInfoChanged 信号
- [ ] 帧计数 + frameCountUpdated 信号（驱动时间显示）
- [ ] VideoPlayer 前后端集成：按钮 → play/pause/resume/stop，信号 → UI 更新
- [ ] 测试播放不同格式文件

### 交付

- 可播放视频的完整版本

## 7. 风险管理

| 风险 | 对策 |
|---|---|
| FFmpeg8 API 变更 | 使用最新 API，禁用废弃声明 |
| 多线程同步 | Qt 信号槽 + QMutex |
| OpenGL 渲染性能 | 双缓冲纹理 + PBO |
| DXGI 兼容性 | 三级回退：ddagrab → DXGI → gdigrab |
