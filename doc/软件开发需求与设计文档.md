# Qt5+FFmpeg8 屏幕录制与播放软件

## 需求与设计文档

---

## 1. 项目概述

### 1.1 项目背景

开发一个基于Qt5和FFmpeg8的Windows平台64位GUI应用程序，实现屏幕录制和视频播放功能。

### 1.2 项目目标

- 实现高质量的屏幕录制功能
- 提供流畅的视频播放体验
- 确保系统稳定性和性能
- 提供简洁易用的用户界面

---

## 2. 技术栈与依赖项

### 2.1 核心技术框架

- **GUI框架**: Qt5 (5.15.13)
- **多媒体处理**: FFmpeg8 (最新API)
- **编译器**: MinGW64
- **平台**: Windows 64位

### 2.2 开发环境配置

- Qt5路径: `X:\Qt\5.15.13\gcc12`
- FFmpeg8路径: `D:\Program\ffmpeg`
- MinGW路径: `D:\Program\mingw64_gcc12`

### 2.3 API使用规范

- 必须使用FFmpeg8最新API
- 禁用废弃或被标记为即将弃用的API和数据结构
- 使用Qt5的QOpenGL接口进行视频渲染

---

## 3. 功能需求

### 3.1 屏幕录制功能

#### 3.1.1 录制技术规格

- **录制范围**: 主屏幕，从屏幕坐标原点开始
- **录制尺寸**: 800x600像素固定大小
- **帧率**: 20帧/秒固定
- **数据格式**: 直接获取BGRA数据，不转换为YUV格式
- **压缩方式**: 无损压缩后立即封装
- **封装格式**: 根据无损压缩选择的编译器所适配的封装格式确定

#### 3.1.2 录制技术实现

- 使用AVFilterContext、AVFilter、avfilter_graph_create_filter等FFmpeg API
- 录制线程：截屏、无损压缩、封装串行执行

#### 3.1.3 录制界面控件

- 开始录制按钮
- 停止录制按钮
- 已录制时间显示控件
- 正在录制文件名称显示控件

### 3.2 视频播放功能

#### 3.2.1 播放技术规格

- 使用FFmpeg进行视频解码
- 使用Qt OpenGL接口将数据处理后上传到GPU渲染
- 播放线程：读取、解码、处理与渲染串行执行

#### 3.2.2 播放界面控件

- 开始播放按钮
- 暂停与恢复按钮
- 停止播放按钮
- 视频文件下拉选择列表（浏览workdir文件夹）

### 3.3 文件管理

#### 3.3.1 工作目录

- 程序启动后自动设置exe文件所在目录为工作目录
- 启动时在工作目录中自动创建 `videodir/yyyymmdd` 日期子目录（yyyymmdd为启动时的年月日）
- 日期子目录用于存储当天录制的视频文件
- 播放时浏览当前日期子目录下的视频文件
- 提供清晰的目录结构管理

#### 3.3.2 文件命名规范

- 视频文件名格式：`月日-时-分-秒-毫秒三位.扩展名`
- 示例：`0505-14-30-25-123.mp4`
- 封装格式：根据无损压缩选择的编译器所适配的封装格式确定

### 3.4 界面设计需求

#### 3.4.1 标签页界面

- 主窗口内panel组件包含两个标签页：录制和播放
- 标签页切换实现功能模块的分离
- 提供直观的用户操作体验

#### 3.4.2 音频功能限制

- **明确不支持音频功能**，只支持视频功能
- 录制时仅捕获视频数据
- 播放时仅处理视频流

## 4. 非功能性需求

### 4.1 性能要求

- 录制和播放功能互斥，同一时间只能执行一个任务
- 确保20fps的稳定录制和播放性能
- 内存使用优化，避免内存泄漏

### 4.2 稳定性要求

- 程序运行稳定，无崩溃现象
- 正确处理异常情况
- 资源释放完整

### 4.3 兼容性要求

- 支持Windows 64位平台
- 兼容Qt5.15.13和FFmpeg8

## 6. 模块设计

### 6.1 核心模块

#### 6.1.1 ScreenRecorder (屏幕录制模块)

**职责**:

- 初始化FFmpeg录制环境
- 配置屏幕捕获参数
- 实现录制流程控制
- 管理录制线程

**关键技术**:

- AVFilterGraph配置
- BGRA数据获取
- 无损压缩算法
- 文件封装格式

#### 6.1.2 VideoPlayer (视频播放模块)

**职责**:

- 初始化FFmpeg播放环境
- 视频文件解码
- OpenGL渲染配置
- 播放流程控制

**关键技术**:

- FFmpeg解码器
- Qt OpenGL接口
- GPU数据上传
- 帧同步机制

#### 6.1.3 FileManager (文件管理模块)

**职责**:

- 工作目录管理
- 视频文件列表维护
- 文件命名生成
- 文件读写操作

#### 6.1.4 MainWindow (主界面模块)

**职责**:

- 用户界面布局（标签页设计）
- 标签页切换控制
- 控件事件处理
- 录制/播放状态显示
- 任务互斥控制

#### 6.1.5 TabManager (标签页管理模块)

**职责**:

- 管理录制和播放标签页
- 处理标签页切换逻辑
- 控制功能模块的显示与隐藏
- 确保任务互斥性

### 6.2 数据流设计

#### 6.2.1 录制数据流

```
屏幕捕获 → BGRA数据 → 无损压缩 → 文件封装 → 磁盘存储
    ↓          ↓           ↓           ↓          ↓
 AVFilter   BGRA格式   编码器配置   容器格式   文件系统
```

#### 6.2.2 播放数据流

```
磁盘读取 → 文件解析 → FFmpeg解码 → 数据处理 → OpenGL渲染
    ↓         ↓           ↓           ↓           ↓
文件系统  容器解析   解码器配置  格式转换   GPU上传
```

## 7. 关键技术实现

### 7.1 FFmpeg8 API使用

#### 7.1.1 录制相关API

```cpp
// 过滤器图创建
avfilter_graph_create_filter()
// 过滤器上下文
AVFilterContext
// 过滤器
AVFilter
// 图配置
avfilter_graph_config()
```

#### 7.1.2 播放相关API

```cpp
// 格式上下文
AVFormatContext
// 解码器
AVCodec
// 帧处理
AVFrame
// 包处理
AVPacket
```

### 7.2 Qt OpenGL集成

#### 7.2.1 OpenGL窗口

```cpp
QOpenGLWindow
QOpenGLContext
QOpenGLFunctions
```

#### 7.2.2 纹理上传

```cpp
glTexImage2D()
glTexSubImage2D()
```

### 7.3 线程同步机制

#### 7.3.1 任务互斥

- 使用QMutex确保录制和播放任务互斥
- 状态机管理当前活动任务

#### 7.3.2 线程通信

- 使用信号槽机制进行线程间通信
- 确保GUI线程的响应性
